# Decision Hub — Demo

An interactive prototype of the **Decision Hub**, Life Innovators' facilitation tool for leading client committees through product-configuration decisions.

**▶ Live demo:** https://marshalltilley.github.io/decision-hub-demo/portal/

Use the **Admin / Editor / Viewer** switch at the bottom of the sidebar to preview each user's experience. Everything runs in your browser — no backend, and no data leaves the page. All names and data are fictional ("Generic Life").

*This is a design prototype for demonstration only.*
